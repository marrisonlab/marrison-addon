# Layout impostazioni scanner Commander

Sovrapporre il contenuto di `commander-cookie-settings-layout.zip` alla cartella
`/commander/` del server. Il solo file distribuito è
`public/admin/cookie-scanner.php`.

La checkbox usa una larghezza fissa e rimane accanto alla sua etichetta. Il campo
quota è compatto; note su righe proprie, spaziatura uniforme, ritorno a capo dei
testi lunghi. Documento HTML con charset e viewport mobile espliciti. Le regole
CSS sono limitate alla pagina scanner.

Sintassi PHP verificata, gestore salvataggio identico byte per byte, integrità ZIP
e corrispondenza sorgente verificate. Anteprima PHP renderizzata con dati fittizi,
senza chiavi, chiamate al fornitore o modifiche al database. Il browser integrato
non ha raggiunto il server locale. Dopo il caricamento dello ZIP, verifica online
completata il 21 ottobre 2026: checkbox larga 16 px, centrata verticalmente accanto
all'etichetta; campo quota largo 220 px; note su righe proprie con ritorno a capo.
Nessun overflow orizzontale a 1101 px (larghezza documento e viewport identiche).
Servizio ancora attivo, quota 900. Nessun salvataggio delle impostazioni eseguito
durante la verifica. Screenshot: `commander-layout-live.png`.

Nessun aggiornamento di Marrison Addon richiesto.
